# บทที่ 1 — พื้นฐานภาษา C++ ที่จำเป็นสำหรับ Unreal Engine

โฟลเดอร์ `ch01-cpp/` คือชุดคำสั่งทุกตัวอย่างในบทที่ 1 ในรูปแบบไฟล์ที่คอมไพล์และรันได้จริง แต่ละไฟล์ตรงกับตัวอย่างชุดคำสั่งในหนังสือทีละตัว ผลลัพธ์ที่ได้จะตรงกับกล่อง "ผลลัพธ์การทำงาน (Console Output)" ในหนังสือทุกบรรทัด

บทนี้เป็น C++ มาตรฐาน **ยังไม่ใช้ Unreal Engine และยังไม่ใช้ Rider** ตามที่หนังสือกำหนด (Rider สร้างโปรเจกต์ C++ แบบไม่มี Unreal ไม่ได้) จึงใช้คอมไพเลอร์ธรรมดาที่ติดตั้งง่ายที่สุด

## สิ่งที่อยู่ในโฟลเดอร์นี้

| ไฟล์ | ตัวอย่างชุดคำสั่งในหนังสือ | หัวข้อ |
|---|---|---|
| `01_hello.cpp` | 1.1 | โครงสร้างโปรแกรมพื้นฐาน |
| `02_syntax.cpp` | 1.2 | ตัวแปร เงื่อนไข และการวนซ้ำ |
| `03_pointers.cpp` | 1.3 | Pointer และ Reference |
| `04_struct.cpp` | 1.4 | Struct |
| `05_class.cpp` | 1.5 | Class และ Encapsulation |
| `06_inheritance.cpp` | 1.6 | การสืบทอด |
| `07_polymorphism.cpp` | 1.7 | Virtual Function |
| `08_header_source/` | 1.8–1.9 | การแยกไฟล์ Header และ Source (`GameCharacter.h`, `GameCharacter.cpp`) + `main.cpp` |

`08_header_source/main.cpp` **ไม่มีในหนังสือ** — เพิ่มเข้ามาเพื่อให้ตัวอย่างการแยกไฟล์รันได้ (หนังสือแสดงเฉพาะไฟล์ Header และ Source ซึ่งยังไม่มีจุดเริ่มต้นโปรแกรม)

## วิธีรัน — เลือกอย่างใดอย่างหนึ่ง

**ก. คอมไพเลอร์ออนไลน์ (เร็วที่สุด ไม่ต้องติดตั้งอะไร)**
เปิดเว็บไซต์คอมไพล์ C++ ออนไลน์ใดก็ได้ คัดลอกเนื้อหาไฟล์ `.cpp` หนึ่งไฟล์ไปวาง แล้วกดรัน ใช้ได้กับไฟล์ 01–07 (ไฟล์ 08 มีสามไฟล์ ต้องใช้วิธี ข หรือ ค)

**ข. Windows + MSVC (ทางที่แนะนำสำหรับผู้ที่จะไป Unreal Engine ต่อ)**
1. ติดตั้ง *Visual Studio Build Tools* แล้วเลือกเวิร์กโหลด "Desktop development with C++" (ตัวนี้จำเป็นสำหรับ Unreal Engine อยู่แล้ว จึงไม่เสียเปล่า)
2. เปิด **x64 Native Tools Command Prompt for VS** (ค้นหาใน Start Menu — ต้องเป็นตัวนี้ ไม่ใช่ Command Prompt ธรรมดา)
3. `cd` เข้าโฟลเดอร์ `ch01-cpp` แล้วพิมพ์ `build_all.bat`

รันทีละไฟล์: `cl /EHsc /utf-8 01_hello.cpp` แล้ว `01_hello.exe`

**ค. g++ (Linux, macOS, หรือ Windows ผ่าน WSL/MinGW)**
`bash build_all.sh` หรือทีละไฟล์: `g++ -std=c++17 01_hello.cpp -o hello && ./hello`

## ทดลองทำ — ผลลัพธ์ที่ตรวจสอบได้

ก่อนรันแต่ละไฟล์ ให้ **ทำนายผลลัพธ์ก่อน** แล้วค่อยรันเทียบ นี่คือแบบฝึกที่หนังสือตั้งใจให้ทำ

- `01_hello` → `Hello World!`
- `02_syntax` → `Pass` ตามด้วย `Count: 0` ถึง `Count: 2`
- `03_pointers` → `value = 60` และ `*ptr  = 60` — ถ้าทำนายได้ถูกว่าทำไมทั้งสองค่าเท่ากัน แปลว่าเข้าใจหัวข้อ 1.5 แล้ว
- `04_struct` → `Name: Alice, Age: 25`
- `05_class` → `Hero Health: 100`
- `06_inheritance` → `Animal is eating.` ตามด้วย `Dog is barking.`
- `07_polymorphism` → `Drawing a Circle.` และ `Drawing a Square.` — ลองลบคำว่า `virtual` หน้า `Draw()` ในคลาส `Shape` แล้วรันใหม่ ผลจะเปลี่ยนเป็น `Drawing a generic shape.` สองบรรทัด นี่คือหลักฐานว่า `virtual` ทำอะไร
- `08_header_source` → `Hero Health: 100` (ผลเดียวกับ `05_class` — ต่างกันเพียงคลาสถูกแยกเป็นไฟล์ Header และ Source)

## จุดสะดุดที่พบบ่อย (Common stumbles)

จุดเหล่านี้ดูเล็กน้อย แต่ทำให้ผู้เริ่มต้นจำนวนมากติดอยู่นานเกินควร

- **ไฟล์ 08 คอมไพล์ไม่ผ่าน "undefined reference to main" หรือ "unresolved external"** — คุณคอมไพล์ `GameCharacter.cpp` ไฟล์เดียว ต้องคอมไพล์ `main.cpp` และ `GameCharacter.cpp` **พร้อมกัน** ในคำสั่งเดียว (ดู `build_all`)
- **`GameCharacter.h: No such file or directory`** — คุณสั่งคอมไพล์จากโฟลเดอร์อื่น `cd` เข้าไปใน `08_header_source` ก่อน หรือระบุพาธให้ครบ
- **บน Windows หน้าต่างดำเด้งขึ้นแล้วหายทันที** — โปรแกรมทำงานเสร็จแล้วปิดตัวเอง ให้รันจาก Command Prompt (ไม่ใช่ดับเบิลคลิกไฟล์ `.exe`) ผลลัพธ์จะค้างอยู่ให้อ่าน
- **MSVC เตือน `C4819` หรือคอมเมนต์ภาษาไทยกลายเป็นตัวอักษรแปลก** — เพิ่ม `/utf-8` ในคำสั่ง `cl` (สคริปต์ใส่ให้แล้ว) และบันทึกไฟล์เป็น UTF-8
- **`cl` is not recognized** — คุณเปิด Command Prompt ธรรมดา ต้องเปิด *x64 Native Tools Command Prompt for VS* เท่านั้น
- **ลืม `;` ท้ายบรรทัด** — คอมไพเลอร์มักฟ้องที่ *บรรทัดถัดไป* จากจุดที่ลืมจริง ให้มองย้อนขึ้นหนึ่งบรรทัด
- **`error: 'cout' was not declared`** — ลืม `#include <iostream>` หรือลืม `std::` นำหน้า
- **ลบ `virtual ~Shape()` ออกแล้วมีคำเตือน `-Wdelete-non-virtual-dtor`** — คำเตือนนั้นถูกต้อง คลาสฐานที่มี Virtual Function ต้องมี Virtual Destructor (หัวข้อ 1.6.4) อย่าปิดคำเตือนนี้
