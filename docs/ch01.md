# บทที่ 1 — พื้นฐานภาษา C++ ที่จำเป็นสำหรับ Unreal Engine

โฟลเดอร์ `ch01-cpp/` บรรจุตัวอย่างชุดคำสั่งทุกตัวอย่างของบทที่ 1 ในรูปแบบ Solution `Ch01.sln` ซึ่งเปิดได้ด้วย JetBrains Rider โดยตรง แต่ละตัวอย่างชุดคำสั่งเป็นโปรเจกต์คอนโซลหนึ่งโปรเจกต์ ผลลัพธ์ที่ได้จากการรันตรงกับกล่อง "ผลลัพธ์การทำงาน (Console Output)" ในบทที่ 1 ทุกบรรทัด

บทนี้เป็น C++ มาตรฐานและยังไม่ใช้ Unreal Engine ตามที่งานเขียนกำหนด อย่างไรก็ตาม Rider ไม่สามารถสร้างโปรเจกต์ C++ แบบไม่มี Unreal ขึ้นใหม่ได้ ชุดโค้ดประกอบ (Companion) จึงจัดเตรียมไฟล์โปรเจกต์ไว้ให้ครบถ้วน ผู้อ่านเพียงเปิด Solution แล้วรัน

## เริ่มต้น

1. เปิด `ch01-cpp/Ch01.sln` ด้วย Rider (เมนู *File → Open* แล้วเลือกไฟล์ `.sln`)
2. คลิกขวาที่โปรเจกต์ของตัวอย่างที่ต้องการใน Solution Explorer แล้วเลือก *Run '<ชื่อโปรเจกต์>'* (Ctrl+Shift+F10) Rider จะคอมไพล์และรันตัวอย่างนั้น
3. เปรียบเทียบผลลัพธ์กับกล่อง "ผลลัพธ์การทำงาน (Console Output)" ของตัวอย่างชุดคำสั่งนั้นในบทที่ 1

## ความต้องการของระบบ

- Windows 10 หรือ Windows 11
- JetBrains Rider (ใช้ได้โดยไม่มีค่าใช้จ่ายสำหรับงานที่ไม่ใช่เชิงพาณิชย์)
- Microsoft Visual C++ Build Tools โดยติดตั้งเวิร์กโหลด "Desktop development with C++" (ผ่าน Visual Studio Installer)

เครื่องมือทั้งสามรายการเป็นชุดเดียวกับที่ Unreal Engine 5.8 ต้องการตั้งแต่บทที่ 2 เป็นต้นไป การติดตั้งในขั้นนี้จึงไม่สูญเปล่า Solution กำหนดค่าไว้ที่ x64, C++17, ระดับคำเตือน `/W4` และการเข้ารหัส `/utf-8` ทั้งใน Debug และ Release

## จุดตรวจสอบผลลัพธ์

ก่อนรันแต่ละโปรเจกต์ ผู้อ่านควรทำนายผลลัพธ์จากการอ่านชุดคำสั่งก่อน แล้วจึงรันเพื่อเปรียบเทียบ การที่ผลลัพธ์ตรงกับที่ทำนายไว้คือหลักฐานว่าเข้าใจหัวข้อนั้นแล้ว

- `01_hello` → `Hello World!`
- `02_syntax` → `Pass` ตามด้วย `Count: 0`, `Count: 1`, `Count: 2`
- `03_pointers` → `value = 60` และ `*ptr  = 60` — หากผู้อ่านอธิบายได้ว่าเหตุใดทั้งสองค่าจึงเท่ากัน แสดงว่าเข้าใจหัวข้อ 1.5 แล้ว
- `04_struct` → `Name: Alice, Age: 25`
- `05_class` → `Hero Health: 100`
- `06_inheritance` → `Animal is eating.` ตามด้วย `Dog is barking.`
- `07_polymorphism` → `Drawing a Circle.` และ `Drawing a Square.` — การทดลองเพิ่มเติม: ลบคำว่า `virtual` หน้า `Draw()` ในคลาส `Shape` แล้วรันใหม่ ผลลัพธ์จะเปลี่ยนเป็น `Drawing a generic shape.` สองบรรทัด นี่คือหลักฐานเชิงประจักษ์ของสิ่งที่ `virtual` ทำ
- `08_header_source` → `Hero Health: 100` (ผลลัพธ์เดียวกับ `05_class` ต่างกันเพียงคลาสถูกแยกเป็นไฟล์ Header และ Source)

## ปัญหาที่พบบ่อย

ข้อผิดพลาดต่อไปนี้ดูเล็กน้อย แต่ทำให้ผู้เริ่มต้นจำนวนมากติดขัดนานเกินควร

- **Rider แจ้งว่าไม่พบ toolchain หรือคอมไพล์ไม่ได้เลย** — ยังไม่ได้ติดตั้ง Visual C++ Build Tools หรือติดตั้งโดยไม่ได้เลือกเวิร์กโหลด "Desktop development with C++" ให้เปิด Visual Studio Installer แล้วเพิ่มเวิร์กโหลดดังกล่าว จากนั้นเปิด Rider ใหม่
- **กด Run แล้วได้ผลลัพธ์ของตัวอย่างอื่น** — ปุ่ม Run บนแถบเครื่องมือรันการกำหนดค่าการรัน (Run Configuration) ที่เลือกไว้ใน Run widget ซึ่งยังเป็นของตัวอย่างเดิม ให้คลิกขวาที่โปรเจกต์ที่ต้องการใน Solution Explorer แล้วเลือก *Run '<ชื่อโปรเจกต์>'* (Ctrl+Shift+F10) ทุกครั้งที่เปลี่ยนตัวอย่าง
- **Compiler แจ้งข้อผิดพลาดที่บรรทัดถัดจากจุดที่แก้ไข** — มักเกิดจากการลืมเครื่องหมาย `;` ท้ายบรรทัดก่อนหน้า Compiler รายงานตำแหน่งที่ "พบ" ความผิดพลาด ซึ่งอยู่ถัดจากตำแหน่งที่ผิดจริงหนึ่งบรรทัด
- **`error C2065: 'cout': undeclared identifier` หรือ `error C2039`** — ลืม `#include <iostream>` หรือลืมคำนำหน้า `std::` หน้า `cout` และ `endl`
- **คำเตือนเกี่ยวกับ Virtual Destructor เมื่อทดลองลบ `virtual ~Shape()` ออก** — คำเตือนนั้นถูกต้อง คลาสฐานที่มี Virtual Function ต้องมี Virtual Destructor (หัวข้อ 1.6.4) ผู้อ่านไม่ควรปิดคำเตือนนี้ แต่ควรใส่ Virtual Destructor กลับคืน
