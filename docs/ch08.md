# บทที่ 8 — พฤติกรรมและการตัดสินใจขั้นสูง

สถานะของโปรเจกต์เมื่อสิ้นสุดบทที่ 8 คือแท็ก `ch08` บทนี้วาง Behavior Tree เส้นตรงของบทที่ 7 ไว้ใต้ Selector และเพิ่มกิ่ง `Investigate` ที่ครอบด้วย Decorator Blackboard บนคีย์ `Alerted` (Observer Aborts: Lower Priority) สัญญาณเตือนมาจาก `BP_AlertZone` ในฉากซึ่งเรียก `RaiseAlert()` บน `AEnemyAIController` พร้อมตำแหน่งของเขตเองเมื่อผู้เล่นเดินเข้าเขต ศัตรูละทิ้งจุดลาดตระเวนที่กำลังมุ่งไปทันที เดินมายังเขต หยุดสองวินาที แล้วกลับไปลาดตระเวนต่อจากจุดที่ค้างอยู่ ในแผนที่ `L_Ch08` ซึ่งเป็นสำเนาของ `L_Ch07` ทุก Node ใน Behavior Tree เป็น Node สำเร็จรูปของเอนจิ้น

## เริ่มต้น

1. ดาวน์โหลดไฟล์ zip ของแท็ก `ch08` จากหน้า Releases (หรือ Tags) ของ repository — GitHub สร้างไฟล์นี้ให้อัตโนมัติ ชื่อไฟล์เป็น `<ชื่อ repository>-ch08.zip` แล้วแตกไฟล์ (ทางเลือกสำหรับผู้ใช้ git: `git checkout ch08` แล้วใช้โฟลเดอร์ `companion/HAPBook/`)
2. เปิด Rider เลือก *File → Open* แล้วเลือกไฟล์ `HAPBook.uproject` โดยตรง (วิธีหลัก) หากเปิดไม่สำเร็จ ให้ดูหัวข้อ "ปัญหาที่พบบ่อย" ของ `docs/ch02.md` เรื่อง .NET runtime ทางเลือกสำรองคือคลิกขวาที่ `HAPBook.uproject` เลือก *Generate project files* แล้วเปิดไฟล์โซลูชันด้วย Rider
3. สั่ง Build (เมนู *Build → Build Solution*) รอจนกระบวนการเสร็จสิ้นโดยไม่มีข้อผิดพลาด
4. เปิด Unreal Editor แล้วเปิดแผนที่ `Content/Maps/L_Ch08` ซึ่งมี `BP_Enemy` หนึ่งตัวกับ TargetPoint ลาดตระเวนสามจุด, `BP_AlertZone` บนเส้นทางของผู้เล่น (ตั้ง `Enemy` ไว้แล้ว) และ `NavMeshBoundsVolume` วางไว้แล้ว
5. กด *Play* เมื่อกด Play ตัวละครผู้เล่นของ Template จะปรากฏที่ PlayerStart ซึ่งไม่เกี่ยวกับตัวอย่างของบทนี้ ผลลัพธ์ของบทอยู่ใน Output Log และผู้อ่านสามารถเดินสำรวจฉากได้ระหว่างนั้น
6. เดินตัวละครผู้เล่นเข้าไปในกล่องของ `BP_AlertZone` ขณะศัตรูกำลังเดินไปจุดลาดตระเวนจุดแรก แล้วมองที่ศัตรู: ศัตรูต้องเปลี่ยนทิศมายังเขตก่อนถึงจุดที่กำลังไป จากนั้นเปิดหน้าต่าง *Window → Output Log* พิมพ์ `[BT]` ในช่องกรอง (แล้วเปลี่ยนเป็น `[AI]` สำหรับบรรทัดสุดท้าย) เปรียบเทียบกับหัวข้อ "จุดตรวจสอบผลลัพธ์" ระหว่างเล่น กดปุ่ม Apostrophe (`'`) ขณะกล้องมองเห็นศัตรูในจังหวะที่ผู้เล่นเข้าเขต เพื่อดู Node ที่ทำงานอยู่กระโดดจากกิ่งลาดตระเวนไปกิ่ง `Investigate` และค่าของ `Alerted`

## ความต้องการของระบบ

- Unreal Engine 5.8 (ติดตั้งผ่าน Epic Games Launcher)
- JetBrains Rider 2026.x หรือใหม่กว่า (ใช้ได้โดยไม่มีค่าใช้จ่ายสำหรับงานที่ไม่ใช่เชิงพาณิชย์)

- .NET runtime รุ่นที่ UnrealBuildTool ของ UE 5.8 ต้องการ (ค่า `framework.version` ใน `Engine\Binaries\DotNET\UnrealBuildTool\UnrealBuildTool.runtimeconfig.json` เทียบกับ `dotnet --list-runtimes`)

สถานะเริ่มต้นของโปรเจกต์สำหรับบทนี้คือแท็ก `ch07` บทนี้แก้ `EnemyAIController.{h,cpp}` เฉพาะส่วนที่กำกับว่า "บทที่ 8" และไม่แตะ `EnemyCharacter.*` หรือ `HAPBook.Build.cs`

## จุดตรวจสอบผลลัพธ์

บทบาทมีสองฝ่าย: ผู้เล่นเดินเข้าเขต ส่วนศัตรูที่กำลังลาดตระเวนละทิ้งจุดที่กำลังมุ่งไปแล้วหันมายังเขต ก่อนกด Play ผู้อ่านควรทำนายว่าศัตรูจะเปลี่ยนทิศทันทีที่ผู้เล่นเข้าเขต หรือเมื่อถึงจุดลาดตระเวนก่อน และบรรทัดใดจะเปลี่ยนหาก Observer Aborts เป็น None การเปลี่ยนทิศที่มองเห็นก่อนศัตรูถึงจุดเดิมคือ Observer Aborts และบรรทัดที่สองคือสิ่งที่ยืนยัน Output Log (กรอง `[BT]` แล้ว `[AI]`) ต้องแสดงสี่บรรทัดต่อไปนี้ตามลำดับ หลังบรรทัด `[AI] Possessed ...` ของบทที่ 7 เมื่อเดินเข้าเขตขณะศัตรูกำลังไปจุดที่ 1

```
LogTemp: [BT] Alert raised at AlertZone
LogTemp: [BT] Patrol aborted by Observer Aborts (Lower Priority)
LogTemp: [BT] Investigate: reached AlertLocation, Alerted cleared
LogTemp: [AI] Reached waypoint 1 of 3
```

- บรรทัดที่ 1: จาก `RaiseAlert()` ที่ `BP_AlertZone` เรียกเมื่อ Pawn ของผู้เล่นทับซ้อน โดยส่งตำแหน่งของเขตเอง `AlertLocation` ถูกเขียนก่อน แล้ว `Alerted` จึงเป็นจริง
- บรรทัดที่ 2: จาก `CheckAbortAfterAlert()` 0.1 วินาทีต่อมา การเขียน `Alerted` เรียกผู้สังเกตทุกราย Decorator ประเมินเป็นจริง และเพราะกิ่งที่ทำงานอยู่สำคัญต่ำกว่า จึงร้องขอการยุติ Behavior Tree ยุติ Move To ของกิ่งลาดตระเวน (ผล Aborted ซึ่ง `OnMoveCompleted()` ละเว้น ดัชนีจึงคงเดิม) แล้วเริ่ม Move To ไป `AlertLocation` บรรทัดนี้คือการสังเกตจุดหมายของคำขอปัจจุบัน ไม่ใช่การอนุมานจากค่าที่ตั้งใน Decorator
- บรรทัดที่ 3: จาก `OnMoveCompleted()` เมื่อถึงเขต การจำแนกด้วยจุดหมายผ่าน จึงล้าง `Alerted` Decorator (Lower Priority) ไม่ยุติกิ่งของตนเมื่อเงื่อนไขเป็นเท็จ Wait 2.0 เล่นจนจบ Sequence สำเร็จ Selector ค้นหาใหม่จาก Root
- บรรทัดที่ 4: กิ่งลาดตระเวนกลับมา Move To อ่าน `PatrolLocation` ที่ยังเป็นจุดที่ถูกขัดจังหวะ ตัวเลขจึงเป็น `1` เมื่อเดินเข้าเขตระหว่างจุดที่ 1 (และเป็น `2` หากเข้าเขตระหว่างไปจุดที่ 2) จากนั้นวนต่อ `2 of 3`, `3 of 3`, …
- หาก Wait 2.0 ถูกตัดสั้นหลังบรรทัดที่ 3 (ศัตรูออกจากเขตทันที) แสดงว่า Decorator ยุติกิ่งของตนเองเมื่อคีย์ถูกล้าง ซึ่งเป็นพฤติกรรมของ Self/Both ให้ตรวจว่า Observer Aborts เป็น Lower Priority

การทดลองเพิ่มเติม: เปิด `L_Ch07` แล้ว Play ต้องได้สี่บรรทัด `[AI]` ของบทที่ 7 ทุกอักขระและไม่มีบรรทัด `[BT]` ใด (BB_Enemy มีคีย์ใหม่แต่ไม่มีสิ่งใดเขียนค่า) จากนั้นใน `L_Ch08` เปลี่ยน Observer Aborts เป็น None แล้ว Play ใหม่ (แบบฝึกหัดข้อ 4 ของบทที่ 8)

## ปัญหาที่พบบ่อย

- **มีบรรทัด Alert raised แต่บรรทัดที่สองเป็นคำเตือน `Alerted is set but patrol was not aborted (Observer Aborts = None?)` และศัตรูเดินถึงจุดลาดตระเวนก่อนจึงมายังเขต** — Observer Aborts ของ Decorator Blackboard บน `Investigate` ค้างที่ค่าเริ่มต้น None ให้เลือก Decorator ใน `BT_Enemy` แล้วตั้ง *Observer Aborts* เป็น *Lower Priority*
- **ศัตรูมาถึงเขตแล้ววนกลับมาเขตซ้ำ ไม่กลับไปลาดตระเวน** — `Alerted` ไม่ถูกล้าง สาเหตุที่พบ: Acceptable Radius ของ Move To ใน `Investigate` ใหญ่กว่า 100 (ศัตรูหยุดไกลกว่า 150 หน่วย `WasInvestigateArrival()` จึงไม่ผ่าน) หรือเขตอยู่นอก NavMesh (Move To จบด้วย Blocked/OffPath ไม่ใช่ Success) ให้คงรัศมี 50 และกด `P` ตรวจว่าเขตอยู่บนพื้นสีเขียว
- **เดินเข้าเขตแล้วไม่มีบรรทัดใด** — ตัวแปร `Enemy` ของ `BP_AlertZone` ที่วางในแผนที่ยังว่าง (ต้องตั้งที่อินสแตนซ์ใน Details ไม่ใช่ใน Blueprint) หรือพิน *Cast Succeeded* ของ Cast To HAPBookCharacter ไม่ได้ต่อไปยัง Get Controller หากทั้งสองถูกต้อง ให้ตรวจ Box Collision: *Generate Overlap Events* ต้องกา และ *Collision Presets* ต้องทับซ้อนกับ Pawn ได้ (`OverlapAllDynamic`)
- **มีบรรทัด Alert raised แต่ศัตรูไม่ตอบสนองเลย และไม่มีคำเตือน** — ชื่อคีย์ใน `BB_Enemy` ไม่ตรงกับค่าคงที่ใน C++ (`Alerted`, `AlertLocation` ทุกอักขระ) `GetKeyID()` คืนค่าไม่ถูกต้อง ผู้สังเกตจึงไม่ถูกลงทะเบียน และ Decorator ที่ชี้คีย์ชื่ออื่นไม่เห็นค่า
- **ศัตรูเดินผ่านเขตแล้วยกสัญญาณให้ตนเอง** — กราฟใช้ Other Actor โดยไม่ Cast เป็น `HAPBookCharacter` ให้เพิ่ม Cast ตามสูตร ศัตรูเป็น `EnemyCharacter` การ Cast จึงล้มเหลวและกราฟหยุด
- **ศัตรูใน `L_Ch07` หยุดหลังจุดแรก** — ให้ตรวจว่าไม่มี `BP_AlertZone` ใน `L_Ch07` และ `BT_Enemy` ที่แก้แล้วยังมีกิ่งลาดตระเวนครบ (Move To `PatrolLocation` → Wait 1.0) หากยังเกิด ดู "ปัญหาที่พบบ่อย" ของ `docs/ch07.md`
- **Node Decorator ไม่มีตัวเลือก Lower Priority** — Decorator ถูกวางบน Task แทนที่จะวางบน Sequence `Investigate` (บน Task โหมดที่อนุญาตต่างกัน) ให้ลบแล้วเพิ่มใหม่ที่ Sequence
