# บทที่ 3 — สถาปัตยกรรมแบบผสมผสานและกระบวนการพัฒนาซอฟต์แวร์ใน Unreal Engine

บทที่ 3 เป็นบทเชิงแนวคิด นำเสนอเหตุผลเชิงสถาปัตยกรรมของสถาปัตยกรรมแบบผสมผสาน (Hybrid Architecture Pattern: HAP) และวงจรการพัฒนาด้วย C++ บทนี้ไม่มีโค้ด (Code) ในชุดโค้ดประกอบ (Companion) และไม่มีแท็ก (Tag) ของบท

## เริ่มต้น

ไม่มีขั้นตอนสำหรับบทนี้ ผู้อ่านศึกษาเนื้อหาในตัวเล่มและทำแบบฝึกหัดท้ายบท สถานะของโปรเจกต์ (Project) `HAPBook/` ก่อนบทนี้คือ Tag `ch02` และ Code ชุดถัดไปอยู่ในบทที่ 4 (Tag `ch04`)

## ความต้องการของระบบ

ไม่มีข้อกำหนดเพิ่มเติม ความต้องการของระบบสำหรับบทที่มี Code ระบุไว้ใน `README.md` ของ Companion

## ไฟล์และตัวอย่างชุดคำสั่ง

ไม่มีไฟล์ (File) ตัวอย่างชุดคำสั่งที่ 3.1 ในบทที่ 3 เป็นรหัสเทียม (Pseudocode) ของตรรกะ Blueprint ที่ทำงานทุกเฟรม (Frame) ใช้เพื่ออธิบายภาระงาน (Workload) ไม่ใช่ Code ที่ผ่านการคอมไพล์ (Compile) ได้

## จุดตรวจสอบผลลัพธ์

ไม่มีจุดตรวจสอบเชิงโปรแกรม (Program) ผลลัพธ์ที่ตรวจสอบได้ของบทนี้คือคำตอบของแบบฝึกหัดตัดสินใจวางตำแหน่ง Code (ข้อ 4–6) ซึ่งต้องสอดคล้องกับเกณฑ์การวางตำแหน่ง Code ในบทที่ 15

## ปัญหาที่พบบ่อย

ไม่มีปัญหาเชิงเครื่องมือสำหรับบทนี้ ผู้อ่านที่ต้องการทดลองแนวคิดของบทนี้ใน Project จริง ให้เริ่มจาก `docs/ch04.md`
