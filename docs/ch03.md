# บทที่ 3 — สถาปัตยกรรมแบบผสมผสานและกระบวนการพัฒนาซอฟต์แวร์ใน Unreal Engine

บทที่ 3 เป็นบทเชิงแนวคิด นำเสนอเหตุผลเชิงสถาปัตยกรรมของสถาปัตยกรรมแบบผสมผสาน (Hybrid Architecture Pattern: HAP) และวงจรการพัฒนาด้วย C++ บทนี้ไม่มีโค้ดประกอบ และไม่มีแท็กในชุดโค้ดประกอบ

## เริ่มต้น

ไม่มีขั้นตอนสำหรับบทนี้ ผู้อ่านศึกษาเนื้อหาในตัวเล่มและทำแบบฝึกหัดท้ายบท สถานะของโปรเจกต์ `HAPBook/` ก่อนบทนี้คือแท็ก `ch02` และโค้ดชุดถัดไปอยู่ในบทที่ 4 (แท็ก `ch04`)

## ความต้องการของระบบ

ไม่มีข้อกำหนดเพิ่มเติม ความต้องการของระบบสำหรับบทที่มีโค้ดระบุไว้ใน `README.md` ของชุดโค้ดประกอบ

## ไฟล์และตัวอย่างชุดคำสั่ง

ไม่มีไฟล์ ตัวอย่างชุดคำสั่งที่ 3.1 ในบทที่ 3 เป็นรหัสเทียม (Pseudocode) ของตรรกะ Blueprint ที่ทำงานทุกเฟรม ใช้เพื่ออธิบายภาระงาน ไม่ใช่โค้ดที่คอมไพล์ได้

## จุดตรวจสอบผลลัพธ์

ไม่มีจุดตรวจสอบเชิงโปรแกรม ผลลัพธ์ที่ตรวจสอบได้ของบทนี้คือคำตอบของแบบฝึกหัดตัดสินใจวางตำแหน่งโค้ด (ข้อ 4–6) ซึ่งต้องสอดคล้องกับเกณฑ์การวางตำแหน่งโค้ดในบทที่ 15

## ปัญหาที่พบบ่อย

ไม่มีปัญหาเชิงเครื่องมือสำหรับบทนี้ ผู้อ่านที่ต้องการทดลองแนวคิดของบทนี้ในโปรเจกต์จริง ให้เริ่มจาก `docs/ch04.md`
