## หลักการ: หนึ่งโปรเจกต์ที่เติบโตทีละบท

`UEProject/` เป็นโปรเจกต์ Unreal ที่ **เล็กที่สุดเท่าที่จะทำได้** (เทมเพลต Blank C++ ไม่มี Starter Content) และ **แต่ละบทคือรากฐานของบทถัดไป** — ระบบปัญญาประดิษฐ์ในหนังสือถูกสร้างขึ้นทีละส่วนตั้งแต่บทที่ 7 ถึง 13 บนโปรเจกต์เดียวกันนี้

ทุกบทที่มีโค้ดจะมี **git tag** ชื่อตามบท (`ch02`, `ch04`, … `ch14`) ซึ่งคือสถานะของโปรเจกต์ ณ จุดจบของบทนั้น

- **เริ่มบทใหม่จากจุดที่หนังสือคาดหวัง:** `git checkout ch06` แล้วเปิดโปรเจกต์ — คุณจะอยู่ตรงจุดเดียวกับผู้อ่านคนอื่นที่เพิ่งจบบทที่ 6
- **ดูว่าบทหนึ่งเพิ่มอะไร:** `git diff ch06 ch07` คือรายการทุกบรรทัดที่บทที่ 7 เพิ่มเข้ามา
- **ไม่ถนัด git:** ไปที่หน้า *Releases* ของ repo นี้ มีไฟล์ zip ของทุก tag ให้ดาวน์โหลดโดยตรง

บทที่เป็นแนวคิดล้วน (บทที่ 3, 15, 16) ไม่มีโค้ด และ `docs/` ของบทนั้นจะบอกไว้
