# ชุดโค้ดประกอบ — สถาปัตยกรรมปัญญาประดิษฐ์สำหรับเกมด้วย C++ และ Blueprint ใน Unreal Engine

ชุดโค้ดประกอบนี้บรรจุโค้ดฉบับสมบูรณ์ที่ทำงานได้จริงของทุกบทที่มีการลงมือปฏิบัติในงานเขียน ไม่มีส่วนที่ผู้อ่านต้องเดาหรือเติมเอง จัดทำขึ้นสำหรับผู้อ่านที่ต้องการลงมือทำตามไปพร้อมกับการอ่าน และสำหรับผู้อ่านที่ติดขัดระหว่างทางและต้องการสถานะที่ทำงานได้ถูกต้องแน่นอนไว้เปรียบเทียบกับงานของตนเอง

## ความต้องการของระบบ

- Windows 10 หรือ Windows 11
- JetBrains Rider (ใช้ได้โดยไม่มีค่าใช้จ่ายสำหรับงานที่ไม่ใช่เชิงพาณิชย์)
- Microsoft Visual C++ Build Tools พร้อมเวิร์กโหลด "Desktop development with C++"
- Unreal Engine 5.8 (ตั้งแต่บทที่ 2 เป็นต้นไป)

ชุดโค้ดประกอบทั้งหมดได้รับการทดสอบบนสภาพแวดล้อมข้างต้นเท่านั้น ซึ่งเป็นสภาพแวดล้อมเดียวกับที่ใช้ทดสอบเนื้อหาในงานเขียน

## จุดเริ่มต้น

ผู้อ่านเริ่มจากคู่มือประจำบทใน `docs/chNN.md` เสมอ คู่มือแต่ละบทระบุขั้นตอนการเปิดและรัน จุดตรวจสอบผลลัพธ์ที่ควรได้ และจุดสะดุดที่พบบ่อยพร้อมแนวทางแก้ไข

| บท | โค้ด | คู่มือ |
|---|---|---|
| 1 | `ch01-cpp/Ch01.sln` (โซลูชันสำหรับ Rider ประกอบด้วยโปรเจกต์คอนโซล 8 โปรเจกต์) | `docs/ch01.md` |
| 2 เป็นต้นไป | `HAPBook/` (โปรเจกต์ UE 5.8 เปิดด้วย `HAPBook.uproject`) | `docs/ch02.md`, `docs/ch03.md`, … |

## โครงสร้าง

```
ch01-cpp/        บทที่ 1: C++ มาตรฐาน เปิดด้วย Rider ผ่าน Ch01.sln (ยังไม่ใช้ Unreal Engine)
HAPBook/         บทที่ 2 เป็นต้นไป: โปรเจกต์ Unreal Engine 5.8 หนึ่งโปรเจกต์ที่เติบโตทีละบท
docs/chNN.md     คู่มือประจำบท
```

`ch01-cpp/` เป็นโซลูชันเอกเทศสำหรับบทที่ 1 เท่านั้นและไม่ถูกนำไปใช้ต่อ งานบน Unreal Engine เริ่มที่ `HAPBook/` ณ แท็ก `ch02`

## หลักการ: หนึ่งโปรเจกต์ที่เติบโตทีละบท

`HAPBook/` เป็นโปรเจกต์ Unreal Engine ที่เล็กที่สุดเท่าที่จะทำได้ (เทมเพลต Blank C++ ไม่มี Starter Content) และแต่ละบทคือรากฐานของบทถัดไป ระบบปัญญาประดิษฐ์ในงานเขียนถูกสร้างขึ้นทีละส่วนตั้งแต่บทที่ 7 ถึงบทที่ 13 บนโปรเจกต์เดียวกันนี้

สถานะของโปรเจกต์เมื่อสิ้นสุดแต่ละบทมีให้ดาวน์โหลดสองรูปแบบ

- **ไฟล์ zip ในหน้า Releases (วิธีหลัก ไม่ต้องใช้ git):** ดาวน์โหลด zip ของบทที่ต้องการ (`ch02.zip`, `ch04.zip`, … `ch14.zip`) แตกไฟล์ แล้วเปิดโปรเจกต์ ผู้อ่านจะอยู่ที่สถานะเดียวกับผู้อ่านที่เพิ่งจบบทนั้น
- **git tag ชื่อเดียวกัน (ทางเลือกสำหรับผู้ใช้ git):** `git checkout ch06` ให้ผลเช่นเดียวกับ zip ของบทที่ 6 และ `git diff ch06 ch07` แสดงทุกบรรทัดที่บทที่ 7 เพิ่มเข้ามา

บทที่เป็นแนวคิดล้วน (บทที่ 3, 15 และ 16) ไม่มีโค้ดประกอบ
